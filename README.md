# kudaken.com
[![Language](https://img.shields.io/github/languages/top/kudaken0/kudaken.com)](https://github.com/kudaken0/kudaken.com)

[kudaken.com](https://kudaken.com) の公式ソースコードリポジトリです。
このプロジェクトは、Webサイトのフロントエンド構成ファイル（HTML, CSS, JavaScript）を管理しています。

## 概要

このリポジトリには、個人のウェブサイトである **kudaken.com** のソースコードが格納されています。

## 使用フォント
kudaken.comは[LINE Seed JP](https://fonts.google.com/specimen/LINE+Seed+JP)と[Stack Sans Notch](https://fonts.google.com/specimen/Stack+Sans+Notch)を使用しています。

## 使用技術

このプロジェクトは以下の技術スタックで構築されています：

* **HTML5**: サイトの構造とコンテンツ
* **CSS3**: デザインとレイアウト、レスポンシブ対応
* **JavaScript**: 動的なインタラクションと機能

## ディレクトリ構成

主なディレクトリ構成は以下の通りです：

```text
kudaken.com/
├── main/          # サイトのメインソースコード（HTML/CSS/JSアセット等）
└── README.md      # プロジェクト説明ファイル（本ファイル）
